# 思维导图：实现方向与学习用途

课程内知识地图沿用现有绿色工作台，默认先看整门课，再进入章节。图的结构、片段和页码来自当前有权限的教材；学生可以保存个人笔记与显示标题校正。当前交付范围见[技术与验收报告](submission-report.md)。

## Direction contract

**THESIS**：把教材组织成可以逐层展开、遮挡后回忆的思维导图，让学生先形成全课框架，再复习一章。图的数据必须来自完整且清理过的教材层级。

**OWN-WORLD**：保留现有绿色工作台、中文无衬线和原生表单。当前中心的一级分支按顺序配色，子分支继承所属颜色；同一中心展开时配色稳定，聚焦新的中心后按新分支重新分配。曲线表达包含层次，不表示已证明的因果或先修关系。

**STORY**：学生看到课程与全部章节，进入一章，展开知识点，读教材短片段并定位原页，用自己的话保存理解笔记；再遮住名称回忆，点击核对，或交给助教讲解与追问。标题提取错误时可核对教材后保存个人显示校正。

**FIRST VIEWPORT**：页头说明用途，搜索和模式切换在图上方。导图占主要面积，桌面为中心根与两侧章节；窄屏重排为有曲线连接的纵向导图。节点详情在图下方，不用目录侧栏挤占图。

**FORM**：用户指定思维导图，是已建立页面内的明确局部改造；seed key 为 `user-pinned-mindmap`，无需新品牌或概念抽签。标志交互是“看结构→遮住分支→自行回忆→逐个揭示”。

**核对方式**：按来源检查完整章节、聚焦与搜索、回忆揭示、个人注记、原页定位和导出。设计约定维护于 `ui-design-guidelines.md`；结构与权限行为以当前代码和具体验收记录为准。

## 学习价值的边界

- 导图支持章节归类和主动回忆，不能凭界面验收宣称学习成绩已提高。
- 回忆模式只记录本次揭示，不将“看过答案”当成掌握度。
- 教材片段是原文依据，不冒充模型已核准的知识总结。自动标题层级仍需结合原页核对。
- 真实节点不受旧180节点概览采样影响；展开和聚焦只改变可见内容，不删除知识点。
- 没有题目作答证据时显示未测，不把未知掌握度显示成0%。
- 标题校正和笔记只属于当前学生；原标题、节点编号、来源与原文保留，个人笔记不冒充教材依据。回忆模式在揭示前同时隐藏个人笔记和原文。

## 真实教材暴露的文字层问题

操作系统教材物理第892页的可见标题是“第七章 操作系统接口”，但其嵌入字体的文字映射把“口”提取成了又部首，规范化后显示“又”。像素与字体映射核对证据保存在本地私有验证目录。本轮通过按学生保存的显示标题校正解决这个节点的可读性，未重写 PDF、摄取片段或对全书进行“又→口”替换；其它自动标题仍需核对。
