# 学思同行：需求分析与开发目标

## 来源与产品定位

原始参赛文件为《智能体创新实践大赛参赛手册.docx》和中兴赛道报名表，选择中兴赛道命题二“专业课助教智能体”。材料证据与评分拆解见 [requirements-evidence.md](requirements-evidence.md)；报名原件由参赛者向组委会提供。

目标用户是希望在专业课学习中持续理解概念、解题、发现薄弱点的学生。产品采用“课程即助教”的模型：每门课程有自己的资料、概念关联、聊天历史、练习和计划；学生可以创建任意专业课，并导入自己有权使用的电子教材。408四科是内置参考课程，不把产品限定为某一门课。

## 用户旅程

1. 从演示入口开始，或注册自己的学习账号。
2. 选择408课程；其他专业创建自己的课程，上传授权资料。
3. 询问知识点，查看助教调用教材检索、概念关联与校验工具的过程。
4. 读引用，继续追问“我理解成……对吗”，纠错后用自己的话重述。
5. 生成练习并作答，查看得分、解释和薄弱概念。
6. 生成适合自己的复习计划，逐日完成，导出自己的学习记录。

## 优先级与明确边界

当前实现包括完整学习流程、证据可见、学生课程隔离和比赛复现。文本型PDF支持真实物理页；MD/TXT/DOCX以解析章节和逻辑段定位，不冒充出版社印刷页。Agent可精读已定位页及相邻文字页；启用视觉服务时可按需核对已就绪PDF的一页图像，单轮最多两页。视觉识别不是确定性证明，真实效果须经独立验收；不能因为工具存在或返回了引用就算该图已正确读出。

整书OCR、纯扫描件全文索引、普适图像公式理解、音视频教学、校内统一身份认证和自动下载任意网站教材仍未实现。按需页图工具不把这些扩展变为已完成能力。默认单文件限制200 MiB、PDF最多2000物理页；超限、损坏、加密、空文件或无法抽取文本应明确提示处理限制。

内置中文资料是项目原创的408补充导学手册及自编题目。许可明确的开放教材另有来源记录；它们与国内408商业教材不完全等价，不应暗示内置了王道、严蔚敏、唐朔飞等书的未授权原文。平台支持导入学生实际使用的合法教材。

## 技术选择与取舍

使用React/TypeScript承载交互，FastAPI提供类型化接口，LangGraph实现有上限的工具决策循环，SQLite保存业务状态。当前生成服务使用Mimo，向量嵌入为独立可选BGE-M3接口，与中文BM25通过RRF合并；不可用时显示词法检索降级。种子资料默认不产生模型费用。已有实际正文足够的基础任务省去额外规划；内部教学失败采用诚实的通用恢复，教学和恢复执行均有限时。

框架数量不是评估指标，核心是实际可复现的调用链和学习记录。

## 评分策略与证据原则

手册评分为落地价值30、闭环稳定25、工程质量20、交互体验15、安全合规10。不能承诺获奖或高分。通过真实演示、可运行源码、错误/边界测试、数据出处、实际工具轨迹来证明实现。所有效果指标必须来自本项目测试；单元测试或原论文结果不代表真实学生学习效果。

## 真实场景验收门槛

文本文档烟测只检查基本业务。完整教材验收核对开头、中段、末章和跨页内容，数值题按当前输入重算，多轮纠错检查刷新留存，并检查私有材料、原页引用、图像不可用时的诚实处理，以及作答—错题—计划—导出闭环。本轮Mimo基础场景、原创教材练习闭环、自动回归及独立启动范围见[交付验收报告](submission-report.md)和[最终用例](test-cases-final.md)。历史整书及跨专业实测按当时模型身份保留，不依据`delivered`或`grounded`自动判定语义正确，也不将其改写为当前模型全部通过。
