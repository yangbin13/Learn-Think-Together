# 学思同行界面维护约定

本文记录实际实现的界面规则，便于继续开发时保持一致。事实来源是 `frontend/src/styles.css`、`frontend/src/views/mind-map.css`、`frontend/src/views/Graph.tsx`、`frontend/src/components/MindMapCanvas.tsx`、`frontend/src/components/MindMapFigure.tsx`、`frontend/src/lib/mind-map.ts` 与已保存的浏览器确认；历史章节/局部关系样式仍见 `frontend/src/views/knowledge-map.css`。2026年10月4日沿既有绿色、中文Sans工作台扩展思维导图和教材图示，没有建立新品牌；继续维护本约定，不为局部功能另造设计系统。

## 视觉和信息层级

沿用绿色学习工作台。主色 `--green: #244f40`，正文 `--ink: #23372e`，次级文字 `--muted: #5f6f65`，页面底色 `--paper: #f7f8f6`，内容面 `--surface: #ffffff`，边界 `--border: #dce3de`，焦点 `--focus: #317b5c`。字体栈为 Noto Sans SC、Microsoft YaHei、系统无衬线。

页面标题24px，常规内容标题18px，正文及主要文本输入16px，常用按钮与标签14px，辅助元数据13px，次要计数12px。选课、提问、查看依据、练习与复习是页面的主任务。标题直接说明用途，不再添加英文眉题、装饰插画或重复口号。

同类信息用列表、细分隔线或明确区域分组。主要动作使用绿色实色按钮，普通动作使用边界按钮，删除使用危险动作样式与确认。课程原色仅用于课程识别；不要用随机色表达不存在的掌握度或关系类型。

## 布局与响应式

桌面侧栏236px，中等宽度216px；主内容随1150、900、700px断点重排。小于700px时改为可关闭的导航抽屉，课程功能用三列页签显示两行。课程行与计划任务保留完整名称，不以更小正文塞进桌面结构。

对话正文尽量保持75ch以内，公式、代码与表格在各自区域内滚动。教材原文与来源信息使用正常正文尺度。当前课程思维导图从完整教材树生成，展开和聚焦只改变可见范围；真实教材的自动提取和未核验提示必须可见。旧局部关系图组件和Dagre仍在仓库中，当前导图使用专门的树布局，不从180节点概览采样，也不使用Dagre布局。

## 课程思维导图

默认显示课程/教材根与主要章节。搜索遍历完整树，匹配个人显示标题、原标题和完整提取路径；进入结果时保留实际祖先语境。分支颜色在 `lib/mind-map.ts` 中按当前中心的一级分支顺序分配，其后代继承同色；聚焦后按新的中心重新分配，只用于识别当前分支归属。曲线是教材包含结构，不凭颜色、左右位置或连接方向推断因果、先修与掌握度。

导图页面最大宽度1600px。以画布实际宽度860px为分界：较宽画布将章节分配到根的左右两侧，较窄画布改为带曲线的纵向结构；这是画布断点，与700px的页面文字/表单断点不同。桌面画布总高600px，窄屏总高随布局在840—1200px间增长。绘制区与底栏是独立布局区域，底栏桌面108px、窄屏152px，节点和曲线不能伸到控件区。密集分支先聚焦再展开，长标题按内容换行，不能删字或把所有知识点压进一屏。

页面标题桌面24px、手机22px；根节点18px，普通节点16px/23px行高，辅助说明12px；详情标题20px、手机18px，教材原文15px/1.9行高。图上的字号还会受到画布缩放影响，验收应测实际显示大小。根使用既有绿色，普通节点以彩色下划线与曲线表达层级，选中态用浅绿色，焦点保留可见轮廓。详情从标题开始，真实祖先路径放在标题下，不恢复“课程框架/当前分支”等重复眉题。

有子项的节点提供开合按钮，根节点也能开合。可见符号24px，实际命中区通过反向缩放维持约44×44px；zoom低于0.64时只隐藏非根局部按钮，可用选中条的“展开此分支/收起此分支”、根按钮或“展开一级”。全局“收起全部”仅留下当前中心；“展开一级”从当前可见分支继续展开。按钮实际大小、边缘点击与重叠情况应按缩放后的画面确认，不能只检查CSS原始尺寸。

局部开合通过布局前后锚点差值补偿视口，保持zoom和所点节点的屏幕位置，不能每次自动适应全部节点。首次进入分支会适配，返回已访问分支恢复其展开集合及同宽画布视口；记忆限于当前组件生命周期，课程/教材/内容修订切换可能清空，不承诺跨刷新保留。普通滚轮滚动页面，Ctrl/⌘加滚轮缩放，拖动画布平移；放大、缩小、适应、SVG四个底栏按钮均为44×44px。手机点击节点只选中和揭示，不自动跳到详情；“查看原文与图示”或底栏“查看已选节点”才主动滚动到图下方。

详情将“我的理解”与“教材原文”分开。先显示第一段短原文，其余最多两段折叠，来源链接明确写物理页或逻辑段。个人显示标题旁保留原提取标题；笔记不是教材依据。编辑弹窗复用现有Modal、原生输入和按钮，正文与操作区桌面24px、手机16px内边距，与标题内缘对齐；失败时保留草稿，保存/清空由学生确认提交。

图示作为独立末级节点，用图标及“教材图示/个人图示标注”标识，不借用掌握度。支持隐藏/显示图示；图题、物理页与来源类型必须可核对，自动图题不等于图内知识。本人补充和自动定位均保持未核验说明。详情展示完整原页，不自动裁剪；同页多图请按图号核对，保留原PDF入口、失败重试和主动放大入口。原页弹窗首开按真实长宽比同时适配宽度及64vh高度，并扣除2px边框；100%是整页适配基准，可按50%步长放大至300%，滚动查看后用“整页适配”恢复。此比例不表示源PDF像素1:1。

回忆模式遮住当前中心之外未揭示的分支标题，未揭示的节点不请求详情、不挂载页图，原文、图题与个人笔记同时隐藏，并禁用答案搜索。节点按钮可用键盘Enter揭示，计数只表示本次揭示，不写入mastery；没有作答记录显示“尚未测评”。默认下载PNG图片，底栏主按钮直接显示“下载图片”，生成中禁用并显示状态；保留SVG矢量图备用入口。两种格式只导出当前展开结构，遵守同一遮挡规则，标题转义XML，不含教材正文、笔记或原页图片。图片白底、通常两倍分辨率，标题和说明换行；过大的范围提示进入某章或收起分支，不通过缩小字号生成难以阅读的整书图片。生成失败显示可恢复的错误。导图的助教动作只准备对话草稿，学生明确发送后才请求模型；“让助教看这张图”携带所选文档、图题和物理页。具体使用见 [学习指南](mindmap-learning-guide.md)。

## 操作状态

按钮保留加载、禁用、错误和成功反馈。搜索无结果可以清除搜索；读取失败提供重试。弹窗适用于保护表单输入、删除确认或查看来源，具有Escape关闭、焦点限制与焦点恢复。手机导航同样限制焦点并将背景设为inert；关闭后回到原按钮。

历史预览、复习说明采用可展开内容。收起只是降低初始信息量，不能删除后端记录或省略仍需核对的原文。不要在界面初始化时自行创建收费问答、练习或复习计划。

新增页面先复用现有组件与变量，再验证实际内容的桌面、中等宽度和手机状态。构建成功、检测器无告警和截图好看分别只证明一部分，真实流程与数据保留仍需单独检查。

当前验收摘要见 [提交报告](submission-report.md) 与 [最终用例](test-cases-final.md)。历史私人教材原记录只在工作区保留，不随公开源码分发；单页成功不固化为全书识图能力。私有教材截图不嵌入公开维护文档。
