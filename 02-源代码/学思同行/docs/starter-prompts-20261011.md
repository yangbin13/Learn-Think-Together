# 助教三种模式：修复、回答质量与实测（2026-10-11）

## 范围与判定

原体验账号、原「数据结构与算法图解」课程、174 物理页 / 293 片段教材，使用真实 Mimo、内部浏览器、引用弹窗、实际工具及持久化数据库验收。对话、复核、练习、视觉配置均为 `mimo-v2.6-flash`。原教材和历史未清理，未修改 `.env`。

分别检查是否回答本轮问题、学生能否理解和作答、专业结论是否正确、引用是否支持结论、计算是否实际执行、失败时是否诚实续接。HTTP 成功、JSON 合法和模型复核通过都不能单独证明质量。

没有把题目答案写入提示词，也没有放宽事实、权限或工具执行校验。失败会话、错误类比、不可回答的镜子题、定义泄题、双任务和错误二分变体均保留为失败证据。

## 为什么学生选择学思同行

普通专业课定义、常见题目和基础计算，通用模型已经能够回答。同底模对照中，直接 Mimo 的二分和分页都正确；补充课程身份后，也能给出简短正确的二分纠错。没有做豆包产品实测，不宣称全面优于豆包。

应交付的额外收益：

1. **对齐学生正在用的教材。** 可以核对实际章节、原文、图页与实现约定，避免把常见知识包装为这本教材的内容。
2. **接住学习过程。** 学生陈述尝试，助教先判断，再推进当前一步；会话和引用保存后可以接着学。本次实际检查了纠错与下一步衔接。
3. **核对具体条件。** 计算工具按实际数组、区间、取整或页表执行，展开可看到真实轨迹与参数。

### 减少无收益调用

- 整书总览直接使用有权限的真实前言、目录，没有先语义搜索再反复规划。基础概念正文已足够时直接教学；仍执行事实与引用检查。
- 最终总览、生活讲解、命名递归入门题没有额外规划或补查。旧整书探针曾执行 4 轮规划、15 次搜索、1 次画像读取，却仍漏主题；最终总览 8.72 秒、540 字，没有这些额外调用。
- 计算、代码、原图、比较、实现边界和额外要求继续使用受限工具路径，不能仅因命中概念词就跳过核验。

### 同底模对照的实际代价

直接对照是普通 Mimo 调用，不访问教材、数据库、工具或会话历史，每题只测一次。另补了两题相同课程身份的对照，避免因缺课程上下文错误评价模型。

| 原第二条，补充课程身份 | 16.254 秒 / 811 字，栈主体正确，附加队列和扩容说明存在不准确内容 | 39.39 秒 / 317 字，储物柜类比正确，有实际教材出处 | 解释更集中、来源可查；这一轮延迟更高 |

这是单次观察，不能当成稳定性能基准。只有实际来源、当前学习状态或核验有价值时，才应付出额外开销。

## 内部失败怎样继续回复

1. 原 Agent 的严格拒绝保留，失败草稿、伪引用和未执行工具声明不能通过。
2. 检索、工具、格式、复核等内部失败后，尝试一次普通模型调用，只带必要学生问题，不带失败草稿、旧助教答案或内部报错；提供通用知识或方法，说明尚未核实教材和工具。
3. 不给伪教材引用、页码、图中事实或“工具已验证”声明；数值核验失败只解释方法，不冒充已验证数值。
4. 模型仍不可用或新草稿不安全时，返回诚实的服务端学习续接提示，界面标为「学习续接提示」，不伪装模型生成答案。
5. 额度不足（402）和限流（429）仍明确提示；取消、账号权限和请求合法性保持原边界。

独立真实恢复探针只调用 Mimo 一次，6.018 秒得到栈/盘子通用解释，空引用，未冒充教材原文。浏览器也实际触发协议失败后的续接并保存安全回复和降级记录。网络完全不可用时不能保证取得模型知识答案；续接提示不能等同正确知识解答。
