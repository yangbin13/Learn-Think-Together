# 学思同行 · 学习工作台

React 19 + TypeScript + Vite 界面。所有课程、教材、会话、练习、概念掌握度和复习记录来自后端 API；界面不保存平台密钥。

## 本地开发

```powershell
cd frontend
npm ci
npm run dev
```

开发端口 `5173`，`/api` 代理到 FastAPI `127.0.0.1:8765`。`npm run build` 执行 TypeScript 检查并生成 `dist/`，可由后端同源托管。

## 代码入口

- `src/api.ts`：类型、Cookie API 客户端、SSE 读取、错误处理、教材位置标识。
- `src/views/`：认证、课程书架、学习仪表板、助教会话、教材管理、知识地图、练习与复习计划。
- `src/components/Markdown.tsx`：安全 Markdown/GFM 与 KaTeX 数学渲染；规范化代码外的 LaTeX 括号分隔符。
- `src/components/ui.tsx`：可聚焦弹窗、异步数据与加载/空状态组件。
- `src/styles.css`：森林绿与暖纸色的响应式工作台，使用本机字体，无外部字体服务依赖。

会话切换与停止生成会终止当前读取，并使用请求身份避免回复写入其他会话。SSE 流的未完成答复会显示明确提示。内置教材和用户上传内容的逻辑段与 PDF 物理页分别标示；计算工具证据直接显示工具输出，不请求教材下载。

练习历史支持恢复未提交题目和查看已提交解析。复习勾选与错题状态都写入持久后端。未练习的掌握度与正确率显示「未测」，不制造学习指标。

教材摄取展示后端持久进度：逐页文本提取、片段整理、语义索引与保存。页面只显示实际已处理页数、已完成向量数量和服务器百分比，不模拟进度或预估完成时间。解析报告列出无文本页、短文本页、章节定位来源及图表/公式提取边界。语义服务失败会明确显示关键词检索降级；本人上传的失败教材或降级索引可从列表、原文详情重新尝试，后端可继续未完成批次。

PDF 教材列表、原文详情和回答中的物理页引用支持通过认证的 `/api/documents/{id}/preview` 新标签页查看原 PDF。引用使用 `#page=N` 定位 PDF 物理页，以便核对图表、公式和提取不完整的文字；其他文件格式保持下载查看。
