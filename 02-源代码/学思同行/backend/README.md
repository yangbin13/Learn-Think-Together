# 学思同行后端

运行于 Python 3.11+。从仓库根目录执行：

```powershell
.venv\Scripts\python -m pip install -r backend/requirements.txt
.venv\Scripts\python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8765
.venv\Scripts\python -m pytest backend/tests -q
```

`/api/health` 检查 SQLite 可读，`/docs` 提供 OpenAPI。已构建 `frontend/dist` 时同一个服务提供界面和 SPA 路由；未知 `/api/*` 始终返回接口错误。开发时前端的 5173 代理指向 8765。

配置来自服务器 `.env` 或环境变量，环境变量优先。`LLM_API_KEY`、`LLM_API_BASE`、`LLM_MODEL` 只在服务器使用；教学、工具规划、出题、审核和页图默认共用主模型，需支持 OpenAI 兼容工具调用、流式输出、JSON 和图片输入。`EMBEDDING_MODEL` 默认 `BAAI/bge-m3`；需要语义向量时可用 `EMBEDDING_API_BASE/EMBEDDING_API_KEY` 指定独立服务，留空则沿用主服务地址和Key以兼容旧配置。公开 `.env.example` 默认关闭向量，只用 BM25；本地可开启 BGE-M3，显式留空嵌入模型名也会关闭语义摄取和查询。上传摄取会真实调用向量接口，因此消耗平台额度。种子教材首次摄取仅使用本地解析和分词，不调用模型或向量。`TUTOR_DATA_DIR` 指定数据目录，`TUTOR_DATABASE` 可单独指定数据库路径。公开配置中的 `configured` 只表示主模型凭证和模型名非空，不能证明认证、额度或网络可用。鉴权和网络失败明确返回，不生成演示答案。

每个实际课程问题先由服务器执行当前用户权限内的教材检索，最多六条正文，简单寒暄跳过。LangGraph 接着执行 `planner → tools → planner` 的实际工具循环，最多 4 轮、每轮最多 6 个工具调用。模型自行选择 `search_materials`、`read_material_pages`、`interpret_pdf_page`、`expand_concepts`、`get_learning_profile`、`calculate`、`translate_paging_address`、`simulate_page_replacement`、`simulate_cpu_scheduling`、`bankers_algorithm`、`simulate_disk_scheduling`、`subnet_info`、`shortest_path`、`cache_metrics`、`signed_compound_centroid`、`hydrostatic_vertical_plate`。它可以看到检索结果后改写检索词再次检索，也能精读同一教材最多三页的相邻正文，补齐跨页定义、伪码和条件。只包含标题的片段不能作为事实证据。正文证据最多 18 条，精读的新结果可以替换较早的宽泛命中。之后执行证据整理、上游模型流式教学、引用校验与持久化；SSE 的 `token` 来自上游 `stream=True`，少量尾字符保留以阻断跨片段的隐藏思考标签。Trace 只包括工具名称、检索查询/命中数、结果摘要、时长和业务状态，不记录模型规划内容或思维链。

确定性工具仅白名单运算，没有 eval、系统命令、任意文件读取或网络请求。页置换支持 FIFO/LRU 和每步页框；CPU 调度核验 FCFS 和非抢占 SJF；银行家工具按 Need、Available 和完整安全序列判定请求；磁盘调度支持 FCFS/SSTF/SCAN/LOOK，明确方向、柱面边界和有限请求批次停止条件。子网工具明确 IPv4 与 `/31`、`/32` 语义；最短路是非负有向图 Dijkstra；缓存工具区分 `miss_penalty`（额外缺失代价）与 `miss_total_time`（未命中总时延），只输出所选假设的结果。

分页地址工具一次校验当前逻辑地址、页大小和页表，原子返回页号、偏移、页框和物理地址；未映射页返回 `present=false`，不沿用上轮偏移或猜页框。带符号组合形心支持扣除面积与指定参照坐标，明确相对方向；竖直平板静水工具使用 SI 单位，仅在给出铰点深度时计算关于该参照点的力矩。确定性工具校验输入所定义的数值模型，不自动确认未提供的几何或支座，不作工程安全结论。

SQLite 开启 WAL、外键与有界忙等。用户密码使用随机 salt 的 scrypt，Cookie 为 HTTP-only、SameSite=Lax，数据库只保存会话 token 的哈希。自建课程、上传文件、对话、练习、掌握度、错题和计划均按用户隔离；内置课程原始教材只读，同一内置课中的个人上传也只对本人可见。生产部署应使用 HTTPS，并设置 `COOKIE_SECURE=true`。建议使用一个 Uvicorn worker：异步摄取任务是单进程执行器，数据库持久化任务状态可恢复，但当前没有为多进程部署实现分布式租约。

教材支持 PDF/DOCX/MD/TXT，最多 30 MB。上传先原子记录 `documents` 与 `ingestion_jobs`，返回 202 后在后台处理，启动时重排中断的 processing job。解析页数、切块数和向量百分比逐阶段写入 `Document.progress`；向量每完成一批写入 SQLite，进程中断或服务故障后的重试跳过已完成批次。处理阶段的块不会被检索使用。`Document.quality` 显示文字/空白/短页、兼容字符清洗、章节来源和明确的向量失败原因。`POST /api/documents/{id}/retry` 允许本人重试失败摄取或补全降级向量。删除中的文档不会复活。

PDF 做兼容字符 NFKC 清洗，保护数学上下标和数学字形，仅保守合并连续中文断行、标题汉字间空格；PDF 引用页码始终为原文件物理页。有效 PDF outline 用于章节定位，`text00000` 等重排占位标签被忽略，转而提取真实“第X章/2.1/2.1.1”标题，过滤目录点线、年份和明显正文句子。自动章节及小节图谱按各章轮流选取，显示真实物理页范围，关系为“章节包含”和“教材相邻章节”，仍需人工核验。DOCX、TXT、MD 无可靠渲染分页，引用页码是约 1800 字符的稳定逻辑分段，不能声称原书页码。

`GET /api/documents/{id}/preview#page=N` 在同一权限检查下用 inline PDF 和浏览器原生阅览器定位物理页。`GET /api/documents/{id}/pages/{N}/image` 返回本人可读且就绪的 PDF 原页 PNG；跨用户不可枚举，不支持文件路径参数。使用 pypdfium2/Pillow 按需渲染，长边最多 1800 像素、总像素最多 300 万，PDFium 调用受进程内互斥锁保护。

`VISION_ENABLED=true` 时可调用 `interpret_pdf_page`；`VISION_MODEL` 留空沿用 `LLM_MODEL`。每轮最多两次，页码必须来自本轮检索/精读或学生明确指定的原 PDF 物理页。单页图像通过服务端调用视觉模型，最终教学回答由主模型组织；不会整本自动 OCR。视觉结果标为 `evidence_kind=image`，记录真实文档、物理页、模型与不确定性，不能冒称确定性验证。页图请求及视觉调用失败会明确显示，不能补造图形。

页图核对适合局部单元格、标注、荷载及可辨支座信息。复杂多节点结构图的全部连线不能可靠自动还原：完整拓扑请求只给可辨局部观察，明确说明不能保证列全，需学生核对原图或提供节点—边表后求解。禁止先提供声称完整的连接清单再附一般免责，也不能按常见图标猜未辨明的约束方向。

空文件、坏文件、加密 PDF、纯扫描 PDF 摄取会明确失败；未实现扫描书全量 OCR。图片/矩阵中的数字、原 PDF 缺损公式或错误字形不能凭文字层补造，质量警告和教学指令要求核验原文；按需视觉识别也可能误读，必须允许学生打开原页核对。

中文检索使用 Jieba、中文重叠双字词与 BM25。已经生成向量的个人上传同时做余弦语义检索，通过 RRF 合并；没有向量的种子或向量调用失败时使用本地词法检索，并在工具 trace 明确标识。索引和归一化向量矩阵按用户/课程缓存，每次重新检查当前文档权限、就绪状态与版本签名；删除或重新摄取会使旧缓存失效。语义服务失败不会阻止教材使用。引用片段由服务器从当前用户课程构造，校验回答 `[n]` 是否对应这些真实片段、实际确定性工具结果或明确标记的页图识别；这是出处/编号校验，不是自动证明答案被证据逐句支持，也不是消除幻觉的保证。

会话持久化历史最多取最近 16 条消息。规划上下文清除旧引用及旧位置，不注入会被模型照抄的历史占位符；各次历史教材依据经 SQL 重新鉴权，按 chunk ID 或真实页+摘录恢复后，仅将本轮证据中仍存在的来源绑定为当前编号。最近一次回答没引用时，仍可以恢复更早消息的合法来源。删除或被新检索淘汰的来源，以及旧图像/工具结果，不能自动继承为本轮出处；计算和图像必要时重新核对。

数字引用 `[1]`、`【１】`、`［1］` 在代码之外统一为 `[1]`，代码数组下标保持原样且不作为引用。无效引用/页码、内部占位符或缺少相应教材/图像证据的断言最多触发一次受控教学重试；SSE `answer_reset` 要求客户端清空之前的草稿与引用，最终 `done.final_text` 是通过校验并规范化后应保存/展示的正文。第二次仍未通过则报错且不保存 AI 回答。输出被截断、内容审核中止、坏 JSON、空回答和上游失败立即失败，不能保存成成功 AI 回答或有效题目。引用校验仍不能替代独立的语义核验。

表格数据列中的单元素数值容器、可辨数组/序列或标识符下标也保持不变，避免历史 `[1]` 驻留页框被改成当前引用 `[2]`；明确“来源/引用”列仍支持引注，歧义数学数据推荐用行内代码。带工具计算、解题/苏格拉底模式、强断言或条件/图表/多个小问的正文，会额外进行一次独立模型局部事实复核，输入只有原用户上下文、真实依据、实际工具参数结果与草稿。严格批准/问题 JSON 检查数值、必要充分、隐含假设/参照点、内部矛盾、引用支持与小问覆盖；拒绝沿同一个一次重试预算修正，仍不通过则明确失败。复核不能替代教师或独立金标，Trace 明示其模型审查边界。

仅基于学生给定条件的一个苏格拉底引导问题经复核通过时，可返回 `grounded=null`，表示教材结论的落地判定不适用，不是假造引用或视为已核验。引入新定义/教学事实仍需真实依据；不能以提问形式提前泄露最终解答。

硅基流动每个 stream chunk 的 usage 是本次请求的累计快照，Provider 仅记录最后非空快照一次，避免重复累加；整个 turn 再累加独立的规划、视觉、教学与事实复核请求（含受控重试的请求）。`done.usage` 是模型请求 token 统计，不是平台账户余额或金额账单，不包括独立向量调用。正文模型保持实际教学模型，图像模型记录在图像引用中。

用户中止、客户端断开、教学校验拒绝或上游连接失败时，教学层显式关闭持有的异步生成器，Provider 在 `finally` 关闭 OpenAI 上游 HTTP response。中断不保存未完成 AI 回答，并释放本会话生成锁。关闭连接能释放本地连接资源并向平台传达断开；平台服务端是否立刻停止推理和后续计费仍取决于其取消策略。

408 练习来自人工题库，专题题不足时在 `source` 明确显示匹配数量与其他概念补充提示；上传到内置课不会改变这一出题路径。学生的任意教材专题生成练习需创建自建课并上传本人教材，验证格式、来源、选项、答案范围及明显泄题标签。提交前 API 不返回答案、解析或来源中可能包含的答案；`GET /api/quizzes/{id}` 可恢复未提交练习，提交后才附带判分结果。`BEGIN IMMEDIATE` 确保重复或并发提交只累加一次掌握度、错题和学习记录。练习正确率只反映已做题，不是完整知识掌握的评估；无练习时返回 `null`。规则生成的复习计划优先实际薄弱概念，其次目标对应的已有课程概念；可选真实教材检索把目标命中的章节映射为现有概念，失败或无匹配时在 `basis` 明示离线规则降级。第 6 天起每三天实际重复前面的薄弱/目标概念，`basis` 列明本计划真实复习日，每天总分钟数等于学生输入预算。生成计划不调用 LLM，也不虚构或改写练习掌握度。

测试使用临时数据库和明确命名的 FakeProvider，仅用于隔离验证 auth、课程/教材/会话/题目/计划隔离、真实工具循环及多轮上下文、引用拒绝、隐藏标签过滤、摄取恢复、失败、幂等判分等。本地测试通过不等于真实模型正确率、自动 OCR、完整 Word 页码、部署安全审计或竞赛评分保证。

多目标计划最多分别检索四个有意义的学习意图，保留直接标签匹配，并为每个意图只选最具体的首要已有章节概念；不把同一命中的全部父章或低排名邻节当成新的目标。这使后面的独立目标也能进入计划，不依赖写死某教材的中英文概念别名。
