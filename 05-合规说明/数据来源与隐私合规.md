## 二、隐私保护方式

### 2.1 账号与存储

正式运行时，后端保存用户名、显示名、加盐密码散列、会话令牌散列和学习记录。密码使用加盐 scrypt，不保存明文密码；会话令牌使用 SHA-256 散列。登录失败限流在服务进程内使用来源 IP 和用户名，不写入学习数据库。

对话、笔记、练习与计划保存于部署者本机或服务器的 SQLite，上传文件保存在该部署的数据目录。当前不对数据库正文及教材文件默认加密；部署者应控制数据目录和备份的访问权限。

### 2.2 访问权限与用户控制

后端按登录用户检查私有课程、教材、会话、练习、计划、导出与修改权限。另一账号不能通过猜测资源 ID 读取本人资料。用户可以导出自己的学习记录，删除会话、上传资料及自建课程；资料删除后不再用于新检索，历史引用的原文件入口可能失效。

Cookie 设置 `HttpOnly`、`SameSite=Lax`，需要登录的写请求校验浏览器请求来源。本地 HTTP 演示使用 `COOKIE_SECURE=false`；公开部署应使用 HTTPS 并设置 `COOKIE_SECURE=true`。权限核验记录见[账号隔离验收](../02-源代码/学思同行/docs/validation/ds-account-boundaries-results.json)。

### 2.3 外部模型的数据范围

在线教学会向配置的模型服务发送当前问题、必要历史、检索片段及待核对草稿；启用语义检索时，向量服务收到查询和教材片段；启用视觉阅读时，视觉模型收到实际选中的 PDF 页图及问题。程序不把整个数据库、登录密码或应用会话令牌作为教学上下文发送。

因此，“本人课程内可见”是应用权限范围，**不表示完全离线处理**。可通过 `EMBEDDING_ENABLED=false`、`VISION_ENABLED=false` 关闭对应请求，在线文字教学仍需发送必要上下文。正式运营应向用户说明所选模型服务及其数据处理方式。

## 三、是否使用真实个人信息

**本次参赛演示和公开测试未使用真实学生个人信息。** 不包含真实学生姓名、手机号、学号、身份证号或学校考试成绩。视频中的“体验同学”和随机账号代号为演示账号；作答及掌握度为应用内模拟使用记录，不是真实学生成绩或教育效果研究。教材作者署名属于公开出版信息，按许可保留。

**正式使用时会处理账号及学习数据。** 系统没有要求填写手机号、学号或身份证号，但用户名、显示名、提问、笔记或上传文件可能由用户自行输入真实个人信息。当前没有自动识别并匿名化所有输入的功能，不能将演示材料的情况扩展为“系统永不处理个人信息”。

参赛者报名资料单独保留，不混入作品源码、演示视频及技术材料；如主办方要求报名表，身份字段由参赛者单独提交。

## 四、是否进行数据脱敏

**有。已对参赛输出进行排除和脱敏：**

- 提交包排除实际 `.env`、运行数据库、私人教材、完整私有对话记录、Cookie、访问令牌及其他账号凭证。
- 交付文档不包含可用 API key；源码保留 `.env.example`，凭证字段为空，运行者在本机填写。
- 公开测试结果保留必要题目、状态、数量和核验结论，公共课程示例可包含模型回复；私有教材大段原文、完整私有对话及含凭证的原始模型请求不公开。复制到交付材料的测试报告中，形似凭证的合成测试参数替换为脱敏标记；源码中的合成测试样例不是真实凭证。
- 视频使用随机体验账号和公共课程，未展示真实学生身份及私人教材。

**没有自动全面脱敏功能。** 用户输入和上传资料不会在保存或发送给模型前自动清除全部姓名、联系方式等信息。使用者应避免输入无关敏感信息；部署者也不能把本次交付排除检查当作任意后续数据的匿名化保证。
